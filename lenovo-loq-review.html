Who should buy it?

This is worth considering if you want one machine for gaming, college/work and demanding applications, and you prefer dedicated graphics over an ultralight design.

If you mainly browse the web, use Office/Google Docs and stream videos, a cheaper non-gaming laptop may make more sense.
